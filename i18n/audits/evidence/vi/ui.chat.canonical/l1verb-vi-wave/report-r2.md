### MAJOR
**M-1 `raised_panic.settled` / `.running` — v2 `Đã dừng khẩn cấp` / `Đang dừng khẩn cấp` asserts an effect the operation does not have.**
`dừng khẩn cấp` reads as "emergency stop" (of the network row object that follows). The `network` tool's `panic` op does not stop anything: tool.py:629 describes it as "raise a panic: rotate the secret for every member"; cli.py:744 help "Incident: broadcast a revoke and rotate"; `_cmd_panic` (cli.py:7969-7982) calls relay `panic()` then `set_trust(untrusted, reason="this device raised a panic")`, and `trust` is the separate re-admit step. A user reading `Đã dừng khẩn cấp <net>` can conclude the network/service was halted, not that members were revoked and secrets rotated. This is destructive/permission-class text (guideline: safe wording), and the claim is new in v2 (v1 `kích hoạt khẩn cấp` was awkward — adjective without noun — but made no false effect claim). The translator's reasoning "names the effect without an omitted noun" is what is wrong: the effect named is not the effect.
Suggest (pick one; each 5–6 syllables, ≤22 cells): **`Đã báo động khẩn cấp` / `Đang báo động khẩn cấp`** (faithful to "raised panic", names no false effect) — or **`Đã thu hồi khẩn cấp` / `Đang thu hồi khẩn cấp`** (names the actual revoke; `thu hồi` is the shipped revoke term, ×13 in ui.mesh/ui.browser). First option preferred: it keeps the English metaphor and the row's object shows which network.

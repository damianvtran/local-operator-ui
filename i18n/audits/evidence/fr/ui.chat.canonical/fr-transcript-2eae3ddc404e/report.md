## Findings and acceptance checks

1. **Acknowledgement vs elapsed time — PASS.** `A travaillé` is elliptical third-person passé composé, with the agent supplied by the footer context: “has worked”, not “worked successfully”. It does not mean “it worked” (`Ça a marché`) or “well done” (`Bien joué`). `A travaillé pendant {duration}` retains that neutral receipt and adds only elapsed duration. Neither asserts task completion or success. The source sidecar explicitly requires that distinction, and the callsite chooses the forms using `foot.durationS !== null`.
2. **Terminology — PASS.** I read the canonical catalogue, verified all 241 earlier values unchanged, and generated an English/French concordance across all available `fr/` namespace pairs. `Interrompu` reuses `tool_row.outcome.interrupted` (`interrompu`, canonical line 79); capitalization alone is not a new term. `réponse` agrees with canonical credential_lost (line 30), aside_not_answered (45), reply_requested (238), and the ask-answer namespaces. `Tâche` agrees with canonical jobs/jobs_cancel/job_result (203–204, 234), `ui.chat.run_details.jobs`, sidebar background jobs, `ui.chat.interrupt.stopped_jobs`, and `ui.settings.imports.progress_job` (`Tâche {job} · {state}`). The core French style guide explicitly prescribes job → tâche. No new second word for any of these concepts. Existing `ui.chat.asks.no_answer` uses `Aucune réponse`; adding `donnée` is normal grammatical expansion, not a competing term.
3. **Other semantic distinctions — PASS.** `Non exécuté` is a factual never-ran label distinct from neutral `Interrompu`. `Le début de cette réponse n’est pas à l’écran` describes offscreen earlier text rather than lost data; `Une partie de cette réponse pourrait manquer` preserves uncertainty; `Aucune réponse donnée` does not imply an answer was given.
4. **Placeholders and separator — PASS.** All nine additions match English argument sets exactly. Only worked_for has `{duration}` and job_suffix has `{id}`; seven strings have no arguments. `· Tâche {id}` begins with U+00B7 then a space. The source callsite supplies its preceding space, as required. No ICU plural/select expressions exist in these nine additions; a simple brace-argument check is sufficient for their syntax.
5. **Publication failure body — PASS.** `L’agent n’a pas pu être publié. Réessayez.` is natural French: an explicit past publication failure followed by a brief formal-plural retry instruction, not a progress or status label. It has two short sentences and no gratuitous apology or success implication. The catch branch passes it to `userFacingMessage` only as fallback, matching the context sidecar.
6. **English / Unicode — PASS.** Human lexical review found no untranslated English in the nine strings. Automated exact-English comparison found zero equal pairs (supporting, not replacing lexical review). Argument names remain opaque English tokens by design. All nine values are NFC and contain no U+061C, U+200E/F, U+202A–E or U+2066–9 bidi controls. Apostrophes are typographic U+2019 where used.

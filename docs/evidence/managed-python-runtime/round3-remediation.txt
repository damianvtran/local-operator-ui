## Q1 - a full disk with an identity-broken published runtime

The pre-copy reap protected the published runtime unconditionally, so a runtime that is itself
broken stopped the reap reclaiming the space its own replacement needs. Both directions were
run against the SAME test, with one expression of source between them.

The keep set the round-2 fix introduced (what QA reproduced):

```
$ node scripts/run-desktop-tests.mjs scripts/managed-python.test.mjs
✖ a full disk with an identity-broken published runtime is repaired by reclaiming it (2958.113583ms)
  Error: Command failed: /usr/bin/ditto --noacl <seed> <support>/runtimes/.preparing-6j2pir
  ditto: <support>/runtimes/.preparing-6j2pir/ballast.bin: No space left on device
ℹ tests 23
ℹ pass 22
ℹ fail 1
```

The keep set after this round (the published runtime only while its bytes still hash to the
seed):

```
$ node scripts/run-desktop-tests.mjs scripts/managed-python.test.mjs
✔ a full disk with an identity-broken published runtime is repaired by reclaiming it (3019.801792ms)
✔ a full disk with a reusable published runtime repairs by reuse, with no copy at all (3250.010375ms)
ℹ tests 23
ℹ pass 23
ℹ fail 0
```

What the test does, and why it is the conjunction QA had to build an image for: it creates a
16 MB HFS+ image with `hdiutil`, provisions into it, plants a SECOND runtime generation that is
newer than the published one (the retention rule keeps a root's newest generation, so the
published tree is only reapable while something else is more recent - the shape QA's fixture
had), breaks the published runtime's bytes out of band and gives it 4 MB of ballast, then fills
the volume to a 256 KB reserve. Both tests ASSERT the free space is below the copy's size
rather than assuming it, because each one is vacuous otherwise:

```
$ node -e ...   # in-test assertion, printed on failure
the volume must have less room than the copy needs, or this test proves nothing: N bytes
```

The fixture is 4 MB against QA's 120 MB image and 40 MB runtime; the conjunction is the same one
at a scale the suite can afford, and `ditto` is what decides it either way.

The mirror case - the win QA says must survive - is the second test: an intact published runtime
on a full volume repairs by reuse, asserted as ONE generation in the runtimes root, so no copy
was made at all. It passes with the fix and passed with the round-2 code, which is what makes it
a guard rather than a reproduction.

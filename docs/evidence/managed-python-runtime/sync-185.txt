Branch `fix/managed-python-runtime`, PR #183. Pre-sync head 336835d84, base a8f6bc4b9;
`origin/main` c9a9c6196 (v0.22.5, PR #185, on top of #179 and #149). Merged, not rebased.
Every block below is a command and its own output.

## Why a merge

GitHub reported the PR CONFLICTING / DIRTY. A conflicted PR gets no `pull_request`
workflow runs, so no round could be taken against the head while it stood. The repo's
own convention for this is a merge commit - `0b3351a4b` "chore(sync): merge main (#179)
to unblock the conflicted head" is the precedent, and it was followed by a
re-stamp commit - because a rebase would re-spell every reviewed head the round
citations name.

main's, so `pnpm-lock.yaml` is unchanged (verified, not assumed).
